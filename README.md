## 📖 Project Overview

Agriculture is strongly shaped by seasons, and crop performance can change significantly from one season to another. This project analyses seasonal agriculture data to understand performance patterns, compare seasons, and identify the factors that influence output.

The work is done end to end in a single notebook: loading the dataset, cleaning it, exploring it, visualising trends, and drawing conclusions that can support better agricultural planning.

---

## 🎯 Objectives

- Explore and understand the seasonal agriculture performance dataset
- Clean and prepare the data for analysis
- Compare agricultural performance across different seasons
- Identify trends, patterns, and key influencing factors
- Present findings through clear visualisations and a summary report
